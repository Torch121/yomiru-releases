# Yomiru Releases

Official release builds and binary distributions for the [Yomiru](https://github.com/Torch121/yomiru) application across Android, Windows, and Linux.

---

## Downloads

To download the latest APK, Windows installer, or Linux AppImage, visit the [**Releases**](https://github.com/Torch121/yomiru-releases/releases) tab.

### Supported Platforms:
- **Android**: `app-release.apk` (Universal) and split-ABI APKs.
- **Windows**: `Yomiru-Windows-Setup.exe` (Installer) and portable `.zip`.
- **Linux**: `Yomiru-*-x86_64.AppImage`.
